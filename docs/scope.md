## 2. Security & Access

> *Secure-first by default.*

| Layer | Detail |
|-------|--------|
| **Secure Authentication** | Email, Google & password recovery |
| **Authorization** | Access only permitted actions |
| **Role-Based Access** | Third layer for admin controls |
| **3 Admin Roles** | CEO → Manager → Employees |

- **Public:** Authentication + Authorization
- **Admin:** Authentication + Authorization + Role-Based Access

> CEO controls manager and employee permissions; managers may receive near-full access with CEO-defined restrictions.
